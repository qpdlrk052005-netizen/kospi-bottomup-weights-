# 상향식 시장적응 기업 가중 실험 — 4판 명세 초안

작성일 2026-11-20. 2판 실행, 3판 설계, 탐색 실험(`../explore_delta/NOTES.md` 1~8절)의 결과를 반영한다. 데이터 수집 목록은 `FEATURE_COLLECTION_LIST.md`에 있다.

## 0. 목표와 원칙

- **주 목표:** 표본 밖에서 평균(B0)을 이긴다.
- **진단 지표:** 같은 기업 예측으로 잰 오라클 천장 가운데 표본 밖에서 확보한 비율(포착률). 천장 자체를 목표로 삼지 않는다. 기업 예측의 퍼짐을 키우면 천장도 커지지만 잡음도 커진다(탐색 7~8절).
- **연구 진실성:** 모든 설계·조정은 2015~2021년으로만 하고, 테스트는 계획을 잠근 뒤 한 번만 한다.
- **시점 원칙:** 예측은 t일 장 마감 뒤에 하고 타깃은 t → t+1 수익률이다. t일 장 마감 시점에 알 수 있던 값만 쓴다(공시일·발표일 기준, 해외 시장은 t−1일까지).

## 1. 구조 (수정안 반영)

```
[입력] 분기 재무(공시일 기준) · 일별 거래·수급(60일) · 업종 관계 · 시장 지표(60일)
   │
   ▼
① 기업 예측기 (1단계, 시드 5개)
   재무 GRU + 거래 GRU → 결합 → 업종 GNN(잔차) → ⊕ 시장 GRU → 공유 헤드 → r̂ᵢ
   손실: 기업 다음 날 수익률 MSE
   │
   ▼
② 교차 적합 + 시드 평균
   k년의 r̂ = k년 이전 라벨로만 학습한 예측기 F⁽ᵏ⁾의 예측 (표본 안 r̂ 사용 금지)
   z̄ᵢ = 5시드 평균,  σᵢ = 시드 간 표준편차
   │
   ▼
③ 시총 가중 기준 (δ = 0)
   ŷ_cap = Σ pᵢ z̄ᵢ,   dᵢ = z̄ᵢ − ŷ_cap
   │
   ▼
④ 가중치 MLP (2단계, 주 모델) — 그림과 같은 구조
   δᵢ = MLP([기업 벡터ᵢ ⊕ 시장 벡터ₜ ⊕ dᵢ ⊕ σᵢ])   (벡터는 ①에서 고정)
   시드마다 하나씩 두고, 모두 같은 z̄를 합산한 뒤 지수 예측을 평균
   w = softmax(log p + δ),   ŷ = Σ wᵢ z̄ᵢ
   손실: 지수 MSE + τ·KL(w‖p)
   │
   ▼
⑤ 직접 보정 (대조군) — 같은 z̄, 같은 날짜
   cₜ = 릿지([1, sₜ, Vₜ, Vₜ·sₜ, σ̄ₜ]),  타깃 y − ŷ_cap
   ŷ = ŷ_cap + cₜ
   │
   ▼
⑥ 비교: B0 · B3R · 시총 가중(③) · 직접 보정(⑤) · 게이트(④)
```

Vₜ = Σ pᵢ dᵢ²(기업 예측의 시총 가중 횡단면 분산), σ̄ₜ = Σ pᵢ σᵢ, sₜ = 표준화한 시장 지표다.

## 2. 문제 → 수정 (검증 구간에서 본 문제)

| 문제(근거) | 수정 |
|---|---|
| 가중치 softmax에 시총 출발점이 없음. 지수는 정확히 시총 가중합 | w = softmax(log 시총 비중 + δ). δ = 0이면 시총 가중 합산(내포 기준) |
| 지수 손실 하나로 끝까지 학습하면 기업 예측 통로가 막힘(2판 이중 0 초기화와 같은 구조) | **2단계 학습:** 1단계는 기업 수익률로 임베딩·헤드를 학습, 2단계는 r̂를 고정하고 δ만 지수 손실로 학습. 오라클 설정과 같아져 포착률을 바로 잴 수 있음 |
| 0 초기화로 기울기 차단(진단 1절) | 헤드는 기본 초기화, δ 마지막 층은 N(0, 0.01²) |
| 기업 모델이 복잡할수록 잡음 증가(F2 −14%, F3 −6%, 8절) | 은닉 32, 드롭아웃 0.1~0.2, 가중 감쇠. 같은 입력의 **선형 기업 모델과 항상 비교**하고, 이기지 못하면 선형을 쓴다 |
| 가중치가 움직이면 손실(F1 2018 −17.9%) | 쏠림 벌점 τ·KL(w‖시총), τ ∈ {0, 0.001, 0.01, 0.1}. δ 학습 스텝은 내부 검증으로 고르되 **0스텝(움직이지 않음)도 허용** |
| 소수 기업 쏠림(유효 기업 3.4개) | 작동 관문에 유효 기업 수 하한(시총 가중의 절반)을 추가 |
| 국면마다 최적 가중이 다름(2019 대 2020) | 검증 폴드 4개(2018~2021), 폴드 정규화 점수, 모델 사이 1-표준오차 규칙 |
| 게이트를 표본 안 r̂로 학습했음(탐색 8절 `oracle_bottomup_honest.py`). 표본 안 r̂는 실제와 더 잘 맞아서 게이트가 r̂를 과신함 | **교차 적합:** 2단계 학습·선택·평가에는 해당 연도 전 라벨로만 학습한 예측기의 r̂만 쓴다(stacking, Wolpert 1992, Breiman 1996) |
| 시드마다 가중치가 다른 r̂를 봄 | 기업 예측을 5시드 평균(z̄)한다. 가중치 MLP는 시드별 벡터를 입력으로 받으므로 시드마다 하나씩 둔다(벡터는 시드마다 좌표가 달라 평균할 수 없다). 다만 모두 **같은 z̄**를 합산한다. 시총 기준선은 평균 순서와 무관하게 같다 |
| 가중치 MLP가 비중을 옮겼을 때의 효과를 직접 보지 못함 | 그림의 MLP 입력 [기업 벡터 ⊕ 시장 벡터]에 dᵢ = z̄ᵢ − ŷ_cap(δᵢ를 움직였을 때 지수 예측 변화의 기울기)와 σᵢ(시드 간 표준편차)를 덧붙인다 |
| 가중 효과와 지수 단위 보정을 구분하지 못함 | 직접 보정 릿지를 대조군으로 둔다. δ = g(s)·d 꼴만으로는 지수 예측 변화가 g(s)·Vₜ가 되어 직접 보정과 1차 근사로 같다. 따라서 가중치의 추가 가치는 기업 벡터와 σ에서 나와야 한다 |
| LimitHit 윈저화 붕괴 | 이산 지표는 윈저화·표준편차 나눗셈 없이 평균만 뺌 |
| 시장 상태가 주가 파생뿐 | 시장 GRU에 금리·환율·해외·수급·심리 지표 추가 |
| 기업 예측 정보 부족(기업 단위 R² ≤ 0.5%) | 재무·수급·공매도·이벤트 피처 추가. 2단계 관문으로 효과를 먼저 확인 |

## 3. 학습

- **1단계 (기업 예측기 F⁽ᵏ⁾):**
  - 타깃은 기업 다음 날 수익률(%)이다. 손실 계산에만 학습 구간 1%/99% 윈저화를 적용한다.
  - 손실은 동일가중 기업 MSE이고, 날짜마다 기업 수로 나눠 평균한다.
  - AdamW(1e-3, 가중 감쇠 1e-4), 배치 16일, 최대 20에폭으로 학습한다. 조기 종료는 학습 구간 마지막 1년의 기업 단위 손실로 한다.
  - 연도 k마다 F⁽ᵏ⁾를 k년 1월 1일 전에 실현된 라벨로만 학습한다. 시드는 5개다.
- **교차 적합 예측 (가장 중요):**
  - k년의 r̂는 F⁽ᵏ⁾로만 만든다. 2단계의 학습, 선택, 평가에는 이렇게 만든 r̂만 쓴다.
  - 기업 예측기가 학습한 날의 예측값(표본 안 r̂)은 쓰지 않는다.
  - 2015년은 교차 적합 예측이 없어서 2단계 학습에서 빠진다.
  - 확장 창이라 F⁽ᵏ⁾는 모든 폴드가 함께 쓴다.
    - 검증 단계: k = 2016~2021의 6개 × 5시드
    - 테스트 단계: k = 2022~2026의 5개 × 5시드를 추가
- **시드 평균:**
  - z̄ᵢ는 5시드 평균이고, σᵢ는 시드 간 표준편차다.
  - ŷ_cap = Σ pᵢ z̄ᵢ, dᵢ = z̄ᵢ − ŷ_cap, Vₜ = Σ pᵢ dᵢ², σ̄ₜ = Σ pᵢ σᵢ.
- **2단계 가중치 MLP (주 모델, 그림과 같은 구조):**
  - δᵢ = MLP([기업 벡터ᵢ ⊕ 시장 벡터ₜ ⊕ dᵢ ⊕ σᵢ]), w = softmax(log p + δ), ŷ = Σ wᵢ z̄ᵢ.
  - 기업 벡터는 GNN을 거친 벡터이고, 시장 벡터는 시장 GRU 출력이다. 둘 다 그 해의 F⁽ᵏ⁾가 만든 값으로 고정한다. d, σ는 2단계 학습 구간 통계로 표준화한다.
  - 시드 s마다 MLP를 하나씩 둔다. 각 MLP는 시드 s의 벡터와 공통 d, σ를 받고, 공통 z̄를 합산한다. 최종 예측은 5개의 평균이다.
  - MLP는 은닉 32, 드롭아웃 0.1~0.2이고, 마지막 층은 N(0, 0.01²)로 초기화한다. z̄와 벡터는 고정하고 MLP만 학습한다.
  - 손실은 지수 MSE + τ·KL(w‖p)이다. τ ∈ {0, 0.001, 0.01, 0.1}이고, 스텝 수는 0스텝을 허용한다.
  - 선형 사다리(BU-Lin-δ)에는 임베딩이 없으므로 δᵢ = [xᵢ, dᵢ]ᵀ Θ [1, sₜ]를 쓴다(sₜ는 시장 지표).
- **직접 보정 (대조군):**
  - cₜ = 릿지([1, sₜ, Vₜ, Vₜ·sₜ, σ̄ₜ])이고, 타깃은 y − ŷ_cap이다. 예측은 ŷ = ŷ_cap + cₜ다.
  - 게이트와 같은 z̄, 같은 날짜로 학습한다. λ ∈ {10, 100, 1000, 10000}은 내부 검증으로 고른다.
- **정직한 절차:** 폴드 v마다 다음 순서로 한다.
  1. 2016 ~ v−2년의 교차 적합 z̄로 게이트와 보정을 학습한다. 그리고 v−1년(F⁽ᵛ⁻¹⁾의 예측)으로 τ, 스텝 수, λ를 고른다.
  2. 고른 설정으로 2016 ~ v−1년에 다시 학습한다.
  3. v년(F⁽ᵛ⁾의 예측)에서 한 번만 평가한다.
  - 2018 폴드는 2단계 학습 자료가 2016년 1년뿐이므로 결과를 따로 표시한다.

## 4. 비교 사다리

| 모델 | 무엇을 재나 |
|---|---|
| B0 과거 평균 | 주 목표의 기준 |
| B3R 시총 가중 + 릿지(3판) | 지수 단위 최선 기준 |
| BU-Lin-cap: 새 입력의 선형 기업 모델 + 시총 가중 합 | 새 입력의 가치(선형) |
| BU-Lin-보정: 위 + 직접 보정 | 지수 단위 보정 신호가 있는가(선형) |
| BU-Lin-δ: 위 + 공통 게이트 | 선형 가중의 가치 |
| BU-NN-cap: 신경망 기업 예측 + 시총 가중 합 | 신경망 기업 예측의 가치 |
| BU-NN-보정: 위 + 직접 보정 | 지수 단위 보정 신호가 있는가(신경망) |
| BU-NN-δ단순: 같은 z̄ + δᵢ = [dᵢ, σᵢ, CapPctᵢ]ᵀ Θ [1, sₜ] | 기업·시장 벡터 없이 단순한 가중치만으로 되는가(과적합 점검) |
| **BU-NN-δ (주 모델, 그림의 가중치 MLP)** | 최종 |

모든 BU 모델은 같은 교차 적합 z̄를 쓴다. 기업 예측기는 Lin과 NN 각각 하나씩이고, 시총 가중, 보정, 게이트는 그 위에 얹는 결합 방식만 다르다.

- **연구 질문의 답은 BU-NN-δ 대 BU-NN-cap으로 고정한다.** 어떤 모델이 검증 1등을 하든 바뀌지 않는다. 별도로, 후보 중 검증 1등 모델이 B0를 이기는지 보고한다(`POSTER_RUN_PLAN.md` 1절).
- 성능이 나빠도 그대로 보고한다. 테스트를 본 뒤에는 모델, 설정, 피처를 바꾸지 않는다.
- **주 검정:**
  - 주 모델 대 B0(Clark–West, 주 목표).
  - 주 모델 대 BU-NN-cap(Clark–West, 내포 관계라 순수 가중 효과).
  - 주 모델 대 BU-NN-보정(Diebold–Mariano, 기업 비중을 통한 경로가 직접 보정보다 나은가).
  - 주 모델 대 BU-NN-δ단순(Diebold–Mariano, 그림의 가중치 MLP가 단순 가중치보다 나은가). 주 모델 선정은 바꾸지 않고 결과만 보고한다.
  - BU-NN 대 BU-Lin(Diebold–Mariano, 신경망의 가치).
- **해석 규칙(미리 정함):**

| 표본 밖 결과 | 판단 |
|---|---|
| 보정, 게이트 모두 시총 가중 합을 개선하지 못함 | 현재 입력으로는 시총 기준 예측의 다음 날 오차를 예측할 근거가 약함 |
| 보정만 개선 | 지수 전체를 올리거나 내릴 신호는 있지만, 기업 비중 경로는 비효율적 |
| 가중치 모델이 시총 가중 합과 보정을 모두 개선 | 기업별 정보(기업 벡터, σ)를 쓰는 비중 조정에 추가 가치가 있음 |
- **입력 제거 비교(선택 단계에서만):** 재무 제외, 수급·공매도 제외, 시장 지표 제외, GNN 제외.

## 5. 단계와 관문 (미리 정함)

| 단계 | 내용 | 다음 단계로 가는 조건 |
|---|---|---|
| 1. 데이터 | `FEATURE_COLLECTION_LIST.md`의 자료를 수집하고 시점 정렬 | 커버리지 점검, 미래 정보 누수 점검 통과 |
| 2. 선형 검사(CPU) | BU-Lin-cap, BU-Lin-보정, BU-Lin-δ의 기업 단위 교차 적합 R², 오라클 천장, 정직한 재검증 | 기업 단위 교차 적합 R²가 4폴드 평균 1.0% 이상(현재 0.47%), 그리고 BU-Lin 세 모델 중 하나의 정직한 B3R 대비 이득이 0보다 크고 4폴드 중 3폴드 이상 양수 |

- 계산 시간: 3단계 시작 전에 2판 0단계처럼 1에폭 시간을 재고, 총 예상 48시간 이내일 때만 진행한다.

  - **포착률:** (주 모델 대 BU-NN-cap 이득) ÷ (같은 r̂로 잰 오라클 천장, 옮길 몫 m = 실제 평균 이동 몫).
- **부록:** 부트스트랩 신뢰구간, 방향성(균형 정확도, Pesaran–Timmermann), 경제적 가치(CER).
