# KOSPI 상향식 비중 학습 연구: 실험 결과 정리 (2026-11-22)

> 이 연구에서 돌린 모든 실험의 결과를 한곳에 모았다. 숫자는 결과 파일(부록 B)에서 그대로 옮겼다.
> **확증**은 사전 등록하고 잠근 뒤 테스트를 한 번만 본 결과다. **탐색**은 잠금 이후의 분석이다.

## 0. 한눈에 보기

**결론 다섯 줄**
1. **연구 질문:** 시장 상태에 따라 학습한 비중은 시총 비중을 유의하게 이기지 못했다(MSE −0.04%, p = 0.097).
2. **상향식 예측:** 기업 예측을 합친 지수 예측은 역사적 평균을 유의하게 이겼다(R² 0.44%, p = 0.033). 12개 모델 중 유의하게 이긴 것은 우리 두 모델뿐이다.
3. **하락장 강점:** 하락장 뒤에 강했다. R² 1.73%로, 외부 기준선은 모두 0.07% 이하였다(탐색).
4. **실패 이유:** 구조적이다. 비중을 바꾸면 사실상 예측 수준만 보정된다(하루 −0.06%p). 지수 오차의 99% 이상은 예측할 수 없는 시장 움직임이다(진단).
5. **기업 예측 자체:** 우리 신경망은 MASTER, DTML보다 낫지만 LightGBM과 단순한 이상현상 결합에는 진다(탐색).

## 2. 연구 설정 (요약)

- **데이터:** KOSPI 보통주(상장폐지 포함, 하루 평균 752개), 2014-10~2026-10
  - 기업 일별 피처 41개, 시장 피처 60개, 분기 재무 15개 × 8분기, 업종·상관 그래프
- **1단계 (기업 예측):**
  - NN: 거래 GRU + 재무 GRU + 그래프 어텐션 + 시장 GRU, 시드 5개
  - Lin: 통합 릿지
  - 연도별 교차 적합(k년 예측기는 k년 이전 라벨로만 학습)
- **2단계 (비중):**
  - w = softmax(log p + δ), 손실 = 지수 MSE + τ·KL(w‖p)
  - 후보 7개: cap / correction / δ(선형식) / δ(MLP)
  - 해마다 중첩 검증으로 τ와 걸음 수를 고른다(0걸음 허용)
- **절차:** 검증 2018~2021 → 잠금(2026-11-21 03:22) → 테스트 2022~2026 한 번
- **지표:** OOS R²(B0 대비), Clark–West(단측), Diebold–Mariano(양측), Newey–West lag 5

## 13. 배운 것과 최종 결론

**연구 결과로 배운 것**
1. **상향식 예측은 역사적 평균을 이길 수 있다.** 다만 그 힘은 가중치가 아니라 기업 예측에서 나온다. "The forecasts won; the weights did not."
2. **시총 가중 지수에서는 비중 학습이 구조적으로 제한된다.** 상대 정보가 상쇄되므로 할 수 있는 일은 수준 보정뿐이다.
3. **기업 예측의 순위 예측력은 실제 신호다.** 하지만 지수 예측으로도, 매매 수익으로도 거의 넘어가지 않는다.
4. **한국 시장에서는 복잡한 딥러닝이 단순한 결합과 트리 모델을 이기지 못했다.** 이것이 후속 연구 질문이 됐다(`후속연구.md`).

**방법론으로 배운 것**
1. **교차 적합 없이 비중을 학습하면 거짓 이득이 생긴다.** 이번 사례는 +1.4% → −4.35%였다.
2. **"아무것도 안 하기"(0걸음)를 후보에 넣은 중첩 검증이 손실을 막았다.** 9개 평가 연도 중 5개에서 시총 비중을 유지했다.
3. **사후에 정한 구간(하락 구간)은 착시를 만든다.** 상수 이동 같은 대조군으로 확인해야 한다.
4. **사전 등록과 잠금은 결과가 나쁠 때 가장 큰 힘을 발휘한다.** 무엇이 확증이고 무엇이 탐색인지 분명하게 말할 수 있다.

## 부록 A. 핵심 구현 (간단 버전)

실제 코드는 `code/`에 있다. 아래는 같은 일을 하는 최소 구현이다.

**A.1 학습 구간별 전처리**
```python
def scale(X, train_rows, discrete):              # X: (날짜, 기업, 피처), train_rows: 학습 구간 유니버스 행
    x = X[train_rows]
    lo, hi = np.nanquantile(x, [0.01, 0.99], axis=0)
    lo[discrete], hi[discrete] = -np.inf, np.inf  # 이산 지표는 자르지 않고 평균만 뺀다
    c = np.clip(x, lo, hi)
    mu, sd = np.nanmean(c, 0), np.nanstd(c, 0)
    off = (np.isfinite(x).mean(0) < 0.5) | ~(sd > 0)   # 관측 50% 미만·상수 피처는 끈다
    sd = np.where(discrete | off, 1, sd)
    Z = (np.clip(X, lo, hi) - mu) / sd
    Z[..., off] = 0
    return np.nan_to_num(Z)                       # 결측 = 0 (학습 평균)
```

**A.2 1단계 신경망 (기업 예측)**
```python
class FirmNet(nn.Module):
    def __init__(s, p, q, m, h=32):
        super().__init__()
        s.trade, s.fin = nn.GRU(p + 2, h, batch_first=True), nn.GRU(q + 1, h, batch_first=True)
        s.fuse = nn.Sequential(nn.Linear(2 * h, h), nn.GELU())
        s.gat = GATLayer(h, heads=4)              # 업종·상관 그래프, 잔차 + LayerNorm
        s.mkt = nn.GRU(m, 16, batch_first=True)
        s.head = nn.Sequential(nn.Dropout(.1), nn.Linear(h + 16, h), nn.GELU(), nn.Dropout(.1), nn.Linear(h, 1))

    def forward(s, hist, fin, edges, mkt_hist, node_day):
        hi = s.fuse(torch.cat([s.trade(hist)[1][-1], s.fin(fin)[1][-1]], -1))
        hi = s.gat(hi, edges)
        mt = s.mkt(mkt_hist)[1][-1][node_day]
        return s.head(torch.cat([hi, mt], -1)).squeeze(-1)
# 손실: 날짜별 평균 (r̂ − clip(y, 1%, 99%))², AdamW 1e-3, 16일 배치, 조기 종료(마지막 20%, 인내 2)
# 교차 적합: for k in 2016..2026: 학습 = t, t+1 < k년, 예측 = k년
```

**A.3 2단계 비중과 중첩 검증**
```python
def index_forecast(z, log_p, delta, valid):        # z: 기업 예측(시드 평균), log_p: log 시총 비중
    logw = torch.log_softmax((log_p + delta).masked_fill(~valid, -inf), -1)
    w = logw.exp() * valid
    kl = (w * (logw - log_p)).nan_to_num().sum(-1)
    return (w * z).sum(-1), kl                     # 손실 = MSE(y, ŷ) + τ · mean(kl)

for v in eval_years:                               # 평가 연도
    inner_tr, inner_va = years(2016, v - 2), [v - 1]
    best = {tau: min_over_checks(train(inner_tr, tau), score_on=inner_va) for tau in (0, .001, .01, .1)}  # 0걸음 포함
    tau, steps = argmin(best)                      # 같으면 큰 τ
    model = train(years(2016, v - 1), tau, steps)  # 검증 없이 그 걸음 수만큼
    predict(model, v)                              # v년은 한 번만
```
